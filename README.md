# Financial Analysis Using Python

## 📊 Project Overview

This project analyzes household financial data using Python to understand income, expenses, savings, taxation, and financial patterns across different countries and cities.

The project demonstrates how Python can be used to clean data, perform exploratory data analysis, calculate financial metrics, and create meaningful visualizations.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze household income across countries
- Compare household income and expenses
- Analyze household savings
- Calculate savings percentage
- Identify countries with higher average income
- Identify cities with higher average savings
- Analyze taxation patterns
- Understand the distribution of savings
- Identify relationships between income, expenses, and savings
- Present financial insights using visualizations

---

## 🗂️ Dataset

The project uses the **Global Household Financial Dynamics** dataset.

The dataset contains financial information related to households, including:

- Country
- City
- Total Household Income
- Monthly Savings
- Expenses
- Tax-related information
- Other financial indicators

## 📈 Key Analysis

### 1. Average Income by Country

Calculates the average household income for each country.

### 2. Average Expenses by Country

Compares average household expenses between countries.

### 3. Average Savings by Country

Analyzes the average monthly savings across countries.

### 4. Income vs Expenses

Examines the relationship between household income and expenses.

### 5. Savings Percentage

A new metric is calculated as:

**Savings Percentage = (Monthly Savings / Total Household Income) × 100**

This helps understand how much of household income is being saved.

### 6. City-wise Savings

Identifies cities with higher average household savings.

### 7. Tax Analysis

Examines taxation-related financial patterns in the dataset.

### 8. Savings Distribution

Analyzes how household savings are distributed across the dataset.
