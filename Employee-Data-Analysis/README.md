# Employee Data Analysis using Python

## Project Overview
This project analyzes employee data using Python to identify patterns in salaries, department-wise employee distribution, age distribution, and employee attrition.

## Tools and Libraries
- Python
- Pandas — data cleaning, filtering, grouping, and aggregation
- Matplotlib — data visualization

## Business Questions
1. What is the average monthly income of employees?
2. Which department has the highest average monthly income?
3. How many employees work in each department?
4. Which employees earn more than 10,000?
5. What is the age distribution of employees?
6. How many employees left in each department and job role?
7. What is the attrition rate by department and job role?

## Key Skills Demonstrated
- Importing and inspecting CSV data
- Checking missing values and duplicate records
- Filtering rows and selecting columns
- Grouping and aggregating data using Pandas
- Creating age groups
- Calculating employee attrition rates
- Visualizing data using Matplotlib

## Project Files
- `employee_analysis.py` — Python analysis script
- `employees_analysis.csv` — employee dataset

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib
   ```

3. Run the Python script:

   ```bash
   python employee_analysis.py
   ```
